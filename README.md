# CodeAlpha Machine Learning Internship — Tasks

Submissions for the CodeAlpha Machine Learning virtual internship (September 2026).

## Tasks

### [Task 1: Credit Scoring Model](./credit_scoring_model.py)
Predicts an individual's creditworthiness (good vs. bad credit risk) from financial data
using Logistic Regression, Decision Tree, and Random Forest classifiers, evaluated on
Precision, Recall, F1-Score, and ROC-AUC.
See [README_credit_scoring.md](./README_credit_scoring.md) for full details.

### [Task 2: Emotion Recognition from Speech](./speech_emotion_recognition.py)
Recognizes human emotions (happy, angry, sad, etc.) from speech audio using MFCC feature
extraction and an LSTM deep learning model, trained on the RAVDESS dataset.
See [README_speech_emotion.md](./README_speech_emotion.md) for full details.

## Requirements
Each task's own README lists its specific dependencies. Overall, this repo uses:
```
pandas
numpy
scikit-learn
librosa
tensorflow
```
